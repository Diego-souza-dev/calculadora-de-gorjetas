# Calculadora de Gorjetas em Python 🧾

Um programa simples criado para calcular o valor de gorjetas e o total da conta de um restaurante.

## O que o programa faz:
* Pede o valor da conta.
* Calcula 10% de taxa de serviço.
* Pergunta se o usuário deseja pagar a taxa de forma interativa.
* Mostra o valor final formatado corretamente em Reais (R$).
* Possui um "para-quedas" de proteção contra erros, caso o usuário digite letras em vez de números.

## O que eu aprendi e apliquei neste projeto:
* Uso do laço `while True` para criar repetições de perguntas.
* Tratamento de erros com `try` e `except ValueError`.
* Comandos de interrupção `break` e `continue`.
* Formatação de valores monetários com duas casas decimais usando `:.2f`.
